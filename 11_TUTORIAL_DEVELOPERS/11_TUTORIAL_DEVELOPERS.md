## Getting Started

### Prerequisites
- Python 3.10+
- Git
- Docker (optional)

### Installation

```bash
git clone https://github.com/blakeblackshear/frigate
cd FRIGATE
pip install -e .
```

### Running Tests

```bash
python -m pytest tests/
```

### Project Structure

- `src/` — Main source code
- `tests/` — Test suite
- `tools/` — Development tools
- `anticloud/` — Anticloud overlay
- `docs/` — Documentation
